# Lokosmos Academy

Static Bible and English workbook site for **lokosmos.com**.

`gardenheightsacademy.org` is retired and no longer used for this content.

The same Cloudflare Pages project also receives **gardenheightsacademy.net**
traffic. Each HTML entry point immediately redirects `.net` visitors to
https://gardenheightsacademy.com — the unrelated Garden Heights Academy
novel-reading business, not this site.

The repository root is the deployable site. There is no build step.
