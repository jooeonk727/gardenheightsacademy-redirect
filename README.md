# Word & World Academy

Static Bible and English workbook site for **gardenheightsacademy.org**.

The same Cloudflare Pages project also receives **gardenheightsacademy.net**
traffic. Each HTML entry point immediately redirects `.net` visitors to
https://gardenheightsacademy.com, preserving the original business-site route
while `.org` serves Word & World Academy.

The repository root is the deployable site. There is no build step.
